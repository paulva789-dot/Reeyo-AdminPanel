# Development — Reeyo Admin Panel

Developer notes
---------------
- Follow existing linting and formatting rules (project contains `eslint.config.js` and Tailwind config).
- Keep UI components small and reuse styles from `index.css` and Tailwind tokens.

Running locally
---------------
- `cd Reeyo-AdminPanel/frontend`
- `npm install`
- `npm run dev`

Testing
-------
- Add unit tests using your preferred test runner (not included by default).

Contributing
------------
- Open PRs against `main` branch and include a short summary of changes and screenshots for UI changes.
